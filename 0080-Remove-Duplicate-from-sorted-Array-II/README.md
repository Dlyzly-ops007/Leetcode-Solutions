\# Remove Duplicates from Sorted Array II



Removes duplicates from a sorted integer array in-place such that each unique element appears at most twice. The relative order of the elements is kept the same. Returns the number of elements after the duplicates have been removed.



\## Usage



```python

solution = Solution()

nums = \[1, 1, 1, 2, 2, 3]

k = solution.removeDuplicates(nums) 

\# k returns 5, and the first 5 elements of nums are modified to \[1, 1, 2, 2, 3]
